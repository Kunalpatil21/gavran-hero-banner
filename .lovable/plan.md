# DWIT Farm Production Readiness Audit

## Scope
Polish the existing approved website without redesigning it or changing approved content, imagery, navigation structure, section order, or brand direction.

## Implementation plan
1. Audit all seven pages and shared sections for spacing, alignment, typography, cards, shadows, buttons, images, content, links, forms, and accessibility.
2. Test desktop, tablet, and mobile widths for overflow, cropping, wrapping, navigation, cards, carousels, and footer behavior.
3. Apply only targeted consistency and usability fixes using the existing design tokens and components.
4. Verify training dates, locations, assigned images, product details, maps, CTAs, and route destinations against the approved content.
5. Remove genuine placeholders, debug artifacts, unused production code, and broken references without removing approved features.
6. Validate keyboard focus, labels, alt text, touch targets, reduced motion, lazy image loading, metadata, and critical performance concerns.
7. Run project checks and a final browser pass across every route at representative desktop, tablet, and mobile sizes.

## Technical details
- Preserve the shared header and footer rather than creating alternatives.
- Keep Franchise hidden from shared navigation as previously approved while ensuring its direct page remains functional.
- Keep all four October 2026 training cards and their approved Palghar/Pune images and map links.
- Do not introduce unsupported claims, financial guarantees, new products, prices, locations, or contact information.
